# Crew Briefing Skill

## Format

- **Header**: Flight number, date, and a one-line status (on-track / at-risk).
- **Crew on duty**: One line per crew member — role, name, and duty start time.
- **Compliance**: Duty-time / rest check for each affected crew member; call out any breach explicitly with the limit and the overage.
- **Catering**: Special-meal counts (IATA codes) and total, plus any loading notes.
- **Actions**: A short bulleted list of what ops must confirm before departure.

## Tone

- Factual and operational — no filler.
- Lead with risk: anything non-compliant or at-risk goes near the top.
- Use exact figures (hours, meal counts, limits), never vague qualifiers.

## Length

- Ideal: a single screen — under 200 words.
- If everything is compliant, say so in one line rather than padding.
